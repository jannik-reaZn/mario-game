# Mario 2D Game

This project is a minimal macroquad 2D game, that should behave similar to Mario. The game is developed in rust.

## Building and Starting

Execute the following command

```bash
./scripts/build_and_start.sh
```

The local server starts. The application can be seen under `http://localhost:8000/web/`.

## Goals

- Understand Rust fundamendtals better
- Depper understanding about its ecosystem
- Basic knowledge about Macroquad and WASM
